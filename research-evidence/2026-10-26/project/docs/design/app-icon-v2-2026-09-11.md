# 应用图标设计与生成（AEDResponse）

状态：已重做并由用户确认方向（2026-09-11）。图标是**生成物**，不手工编辑 PNG。

## 本轮改了什么

旧图标是「红底 + 白色心形 + 心电波形」：心形轮廓由四段自造贝塞尔拼成，实际渲染成
一个上宽下尖的洋葱/水滴形，不像心；心电波形线宽为画布的 5.5%（1024 下约 56 px），
过粗，与心形抢视觉；画面上没有任何“AED”字样，产品身份只能靠背景色猜。

新图标按用户三条要求重做：

1. **心形要像心**：改用经典双瓣心形曲线（`classicHeart`，512 框内的 6 段三次贝塞尔），
   有明确的凹口（cleft）、两个圆瓣和收窄到底点的长斜边。这是可识别的通用心形轮廓，
   在任何尺寸下形状都不塌。
2. **线要细**：心电波形线宽从 5.5% 降到 **9/1024 ≈ 0.88%**；除它之外画面上只剩牌匾上
   一条 3 px 的高光描边，没有第二条粗线。
3. **突出 AED**：`AED` 用重量级圆体字（`.black` + rounded design）排在画面下方的
   红色胶囊牌匾上，字高 180、牌匾 676×220，是画面上最大的元素；心形居中作为身份符号，
   心电细线在上方作背景信号。视觉顺序为 **AED → 心形 → 细线**。

配色沿用 App 的急救红：背景 `#E52731 → #920916` 竖向渐变，牌匾 `#DA1621`，图案纯白。

## 生成与再生成

生成脚本：`scripts/make-appicon.swift`（AppKit，纯矢量绘制，无外部依赖）。

```bash
# 只生成到临时目录并出对照图
swift scripts/make-appicon.swift /tmp/aed-icons

# 生成并直接装进两个资源目录
swift scripts/make-appicon.swift /tmp/aed-icons --install
```

产物：

- `<out>/AppIcon-1024.png` —— 1024×1024 的 **8 位 RGB PNG，无 alpha 通道**。
  iOS/Watch 图标禁止透明；脚本内置 PNG 编码器（CRC32 + Adler-32 + `COMPRESSION_ZLIB`）
  直接写色彩类型 2，不经过 `sips`，也不做 JPEG 中转（JPEG 会把白/红硬边糊出振铃）。
- `<out>/preview-{180,120,87,60,40}.png` —— 实机尺寸对照。
- `<out>/contact-sheet.png` —— 审阅用对照图（iOS 与 watchOS 尺寸各一排）。

安装目标（两套内容必须逐字节一致）：

- `ios/AEDResponse/Assets.xcassets/AppIcon.appiconset/AppIcon-1024.png`
- `ios/AEDResponseWatch/Assets.xcassets/AppIcon.appiconset/AppIcon-1024.png`

两套 `Contents.json` 都是 Xcode 15+ 的单尺寸 universal 形式（`platform: ios` /
`watchos`，只声明 1024），由 actool 自动派生其余尺寸，无需手工补小图。
`project.yml` 已为两个 app target 声明 `ASSETCATALOG_COMPILER_APPICON_NAME: AppIcon`。

## 设计约束（以后再改图标时必须保持）

- 图标不得含 alpha 通道。
- 心形必须是可识别的心形轮廓，不得用自造控制点拼出近似形状。
- 线宽上限：除牌匾高光外，任何线不得超过画布的 1%。
- `AED` 必须是画面上最大的元素；缩到 40 px 仍要能读出三个字母。
- 图案元素全部留在中间安全区内（iOS 会做圆角遮罩，边缘不放关键信息）。
