# 视觉核对

依据：用户提供 AED1–AED4；运行图见 screenshots/。原图 426×922（含手机外框），运行图为 iPhone 17 Pro Simulator，402×874 点、1206×2622 像素。使用原生模拟器而非浏览器。

| 对照项 | 核对与实现 |
| --- | --- |
| 背景与主色 | 白色背景、绿色主要动作、浅灰分组、红色警示/退出；未使用图片充当控件 |
| 字体与层级 | 系统字体，行动/设置为大标题；邀请页以求助标题和剩余秒数为中心 |
| 首页结构 | 状态条、附近响应者、地图/列表、发现患者上报、安全说明；人数取动态汇总 |
| 邀请信息 | 距离、预计用时、搜索范围、倒计时、接受/暂不参与；保留真实事件类型 |
| 导航流程 | 三步进度、实际目标地图、到达按钮、Apple 地图、不可用、团队和退出；未合并到达与取到 |
| 设置分组 | 账户与权限、协议记录与系统设置、退出与注销；没有 Ping 或原始坐标 |
| 登录协议 | 四个独立方框，默认空白；点击协议名读全文，勾全后才启用 Apple 登录 |
| 小屏布局 | 首页/设置使用内容标题减少空白；导航的次要按钮单行；内容可滚动以支持大字号 |

保留差异：系统底栏使用 iOS 26 原生样式；离线图为清楚标识的示意图，只有正式业务定位场景才使用 MapKit 路线；服务器未给出 AED 名称和楼层时不显示示例医院地址；人数、半径、距离、时间与连接权限状态不会照抄概念图。模拟器图中的“测试”入口不在正式目标中。

边界：本次验证为原生编译、离线 UI 操作与截图比较，不构成真机 Apple 登录、MapKit 实际步行路线、通知送达或服务器同意记录回执的验证。
