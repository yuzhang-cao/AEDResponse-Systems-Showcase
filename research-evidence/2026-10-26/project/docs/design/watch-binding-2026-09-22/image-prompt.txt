Use case: ui-mockup.
Create a high-fidelity, production-feasible Apple Watch native SwiftUI app UI design presentation for AEDResponse, a Chinese language app. The user's request: the normal watch app should have ONLY the feature of binding to its companion iPhone; very little explanatory text, attractive and easy to understand, no technical dashboard.
Deliver a complete coordinated 2x2 set of FOUR distinct binding-state screens in one large very readable landscape design board. Each screen is a front-facing Apple Watch display silhouette, 46mm proportions approximately 416x496, black OLED background, smoothly rounded corners, slender graphite bezel with no strap, flat orthographic UI (not tilted). Outer board is clean pale neutral gray. Plenty of whitespace and large crisp native PingFang/SF Pro Chinese typography. Four screens same size and consistent precise internal margins. Tiny system clock '09:41' top right, small product name 'AEDResponse' top left. Green accent #30D158, white main text, restrained gray secondary text, amber for failure. Native SF Symbols-style phone/link/check symbols: simple solid/outline system icon, no custom art, no glossy gradients, no decorative illustrations. Native capsule button large comfortable tap target at bottom; no stacked cards, no navigation tabs, no menu.
TOP LEFT screen: large centered paired phone/watch link symbol (gray and green), main heading exactly '绑定 iPhone', supporting copy exactly '在 iPhone 打开 AEDResponse' in at most two short lines, primary green capsule button exactly '开始绑定'.
TOP RIGHT screen: centered subtle progress ring and phone icon, main heading exactly '正在绑定', supporting copy exactly '请保持 iPhone 在附近'. No extra button, no extra explanation.
BOTTOM LEFT screen: green outlined circle containing a clear checkmark and tiny phone glyph, heading exactly '已绑定 iPhone', secondary line exactly '连接正常' in green. No button, leave generous whitespace. This is a DESIGN success-state concept, not actual device evidence.
BOTTOM RIGHT screen: amber phone-link warning icon, heading exactly '暂时无法绑定', supporting copy exactly '请在 iPhone 查看原因', green capsule button exactly '重试'.
Outside and beneath each watch frame put only a small Chinese state caption respectively '待绑定', '绑定中', '已绑定', '绑定失败'. Do not add any other board headlines or explanatory text. Do not add network codes, HTTP, tokens, pairing identifiers, permissions, Fall Detection labels, SOS buttons, diagnostic logs, safety paragraphs, legal paragraphs, server status, or mock medical metrics. Exact Chinese copy and no illegible pseudo-text. Every screen must feel like a minimal polished Apple Watch app that could be directly implemented with native SwiftUI. All on-screen text and controls will be native code, not an image shipped as UI.
