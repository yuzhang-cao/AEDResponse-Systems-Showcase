# 只读管理后台 UI 概念稿

状态：待用户批准。2026-09-08 仅生成静态设计效果图，不代表功能已实现。

## 审阅范围

- [运行总览](01-overview.png)：服务状态、身份人数、设备最近通信、进行中的事件。
- [设备与定位](02-devices.png)：匿名终端列表、协议与权限摘要、位置接收状态、上传策略与实测状态。
- [事件与任务](03-events.png)：事件筛选、生命周期、招募范围和匿名任务人数汇总。
- [AED 资源](04-aeds.png)：已登记资源、最近上报状态、记录时间、匿名相关任务汇总。

四张图是同一套界面的不同页面，不是四种备选风格。图中所有终端、事件、场所、人数、时间和服务状态均为虚构示例，不是本次服务器实测结果。顶部始终显示“界面预览 · 示例数据 · 未连接服务器”。

## 设计约束

- 白色主区域、浅灰侧栏、深色文字、克制的青绿色强调；以表格和详情区为主。
- 仅设计搜索、筛选、刷新和查看，不提供编辑、删除、导入、导出、下载、派单、结束事件或重启服务。
- 不展示手机号、Apple subject、完整身份凭据、精确经纬度、个人地址、个人轨迹或交接照片。
- 终端编号为预览用匿名编号，不使用真实用户或设备 UUID。
- 位置页区分目标上传策略与实测频率。“暂不可用”不能显示为正常或零；未完成验收也不能显示为已通过。
- AED 状态明确为最近上报结果，不保证设备当前物理状态。
- 管理员查看的是匿名状态和聚合进度，不是患者/响应者界面或直接数据库浏览器。

## 实施边界

本轮未实现前端页面、管理 API、管理登录、访问审计或部署；未读取真实数据库或改动后端业务。

当前 `operatorProjection` 并未提供效果图中的全部字段。未来若批准这套界面，需要在不放宽现有业务接口权限的前提下，明确管理端只读投影及字段白名单。效果图不代表已授权普通管理员访问原始数据。

管理端须鉴权并在服务端限制只读，不能只依靠隐藏写按钮；具体管理身份接入与部署范围仍需在开发前明确。未绘制登录页不意味着允许匿名访问。不得把已有具有业务写能力的 operator token 暴露给页面来冒充只读权限。

用户要求“我批准后再进行开发”，因此当前停在设计审阅阶段。后续开发必须先收到批准；不得自动接入生产数据或启动手机/双机测试。
