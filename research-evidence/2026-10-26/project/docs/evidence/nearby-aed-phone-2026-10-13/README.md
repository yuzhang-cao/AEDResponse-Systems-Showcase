## 已完成

- 独立“路线验收”升级至 build 3，generic iOS 构建成功、系统信任环境严格验签成功，普通 USB 安装返回 Complete / exit 0。正式 App 未修改或安装。
- 手机 WhenInUse 精确定位成功，报告精度约 **5.85 米**。原始定位只在手机及本机私有临时文件中，没有复制到项目证据。
- Apple MapKit 用 AED / 自动体外除颤器搜索真实 POI；名称过滤并限定当前位置 3 公里范围。OSM 4 个已知佛山节点也于本次通过官方 API 复核仍标注 defibrillator，坐标为 WGS84，但它们均不在本次手机定位的 3 公里范围内。
- 搜索阶段约 **335 毫秒**，无查询异常、零符合条件的候选。这个结果不证明现实中附近没有 AED。

## 未完成与计时边界

没有真实 AED 候选，因此 **0 条路线计时样本**；正常网络下的 MapKit 速度、单候选与多候选差异、当前地点的最短 AED 路线均未验收。搜索耗时不能当作算路耗时。

已实现的临时计时方式：`ContinuousClock` 仅包围未修改的生产 `MapKitAedRouteCalculator.calculate`，定位、搜索、HTTPS 健康检查、每轮 3 秒间隔、文件保存与 USB 导出均不计入。计划单候选 3 轮、最多 3 候选 3 轮；展示最多 8 个点不等于已测满 8 候选。本次首次请求不保证系统没有缓存。

地图标注不证明现场设备存在、开放或可用，不写入正式 AED 库，也没有创建任何真实求助、分配或领取事件。临时设备模型 `available=false`，只用于查询实际地图步行距离。
